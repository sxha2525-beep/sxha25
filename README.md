# Sxha25

Card personal para Discord, con tres escenas, transiciones animadas, música ambiental y fragmentos de piano con partituras.

La página está hecha con HTML, CSS y JavaScript: no necesita instalación, compilación ni servidor propio.

## Publicar gratis con GitHub Pages

1. Crea un repositorio **público** llamado `sxha25` en GitHub.
2. Sube **todos los archivos y la carpeta `assets`** de este proyecto a la raíz del repositorio. `index.html` debe quedar al lado de `README.md`, no dentro de otra carpeta.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama **main**, la carpeta **/(root)** y pulsa **Save**.
6. Espera unos minutos. La página estará disponible en `https://TU-USUARIO.github.io/sxha25/`.

## Archivos

- `index.html`: entrada y secciones de la web.
- `config.js`: listas, portadas, archivos de audio y partituras.
- `app.js` y los archivos `.css`: comportamiento, estilos y animaciones.
- `assets/`: imágenes, pistas de audio y PDFs.

Para actualizar contenido, modifica los archivos correspondientes y súbelos al mismo repositorio. GitHub Pages publicará la nueva versión automáticamente.
